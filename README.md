## ⚡ Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/DhruvPanchal0312/Data-Science-and-Analysis-With-GenAI.git
   cd "Data Science and Analytics with GenAI"
   ```

2. **Set up a virtual environment (optional for Python notebooks):**
   ```bash
   python -m venv venv
   # Windows
   .\venv\Scripts\Activate.ps1
   # macOS/Linux
   source venv/bin/activate
   ```

3. **Install recommended libraries:**
   ```bash
   pip install numpy pandas matplotlib seaborn streamlit jupyter
   ```
