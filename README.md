## 📌 Repository Overview

This repository documents my structured progression through the **Data Science and Analytics with GenAI** curriculum. From fundamental numerical computing and vectorized data transformations to advanced relational data modeling in Excel/Power BI and full-stack interactive projects, each directory encapsulates practical notebooks, notes, and production-ready code.

```text
📦 Data Science and Analytics with GenAI
├── 📂 EXCEL/          # Advanced formulas, dynamic arrays, Power Query, Power Pivot & DAX
├── 📂 MATPLOTLIB/     # Visual design theory, figure architecture & notebook exercises
├── 📂 NUMPY/          # Vectorized computing, broadcasting & Streamlit mini-apps
├── 📂 PANDAS/         # 9-class deep dive into data manipulation and pipeline cleaning
├── 📂 POWER BI/       # Data acquisition, preparation, M-code & BI modeling
├── 📂 PROJECTS/       # Real-world Excel dashboards & Python portfolio applications
└── 📂 SEABORN/        # 5-part statistical plotting series, distributions & correlation heatmaps
```

## 🗂️ Module Breakdown & Curriculum Highlights

### 🔢 [NumPy — Numerical Python](./NUMPY/)
- **Core Concepts:** N-dimensional array creation, data types, indexing, slicing, and memory layouts.
- **Vectorization & Broadcasting:** Fast array math eliminating slow Python loops, universal functions (`ufuncs`), and matrix algebra.
- **Applied Project:** **[Tic-Tac-Toe Game Engine](./NUMPY/TIC%20TAC%20TOE-%20Numpy/)** — Implemented game logic using 2D NumPy matrices, featuring both a CLI edition and an interactive **Streamlit** web app.

---

### 🐼 [Pandas — Data Wrangling & Analysis](./PANDAS/)
Structured across **9 comprehensive hands-on classes**:
- **Classes 1–3:** Series & DataFrame initialization, label-based vs. positional indexing (`loc`/`iloc`), conditional filtering, and column operations.
- **Classes 4–6:** Missing data detection & imputation (`isna`, `dropna`, `fillna`), string/datetime transformations, sorting, and ranking.
- **Classes 7–9:** Advanced multi-level grouping (`groupby`), aggregations (`agg`), relational joins (`merge`, `concat`), pivot tables, and cleaning messy real-world datasets.

---

### 📊 [Data Visualization — Matplotlib & Seaborn](./MATPLOTLIB/)
- **[Matplotlib](./MATPLOTLIB/):** Figure and Axes object-oriented hierarchy, customizable subplots, custom color maps, line/bar/scatter figures, and visual export formatting.
- **[Seaborn (5 Classes)](./SEABORN/):**
  - *Distributions:* Histograms, Kernel Density Estimation (`kdeplot`), and empirical CDFs.
  - *Categorical:* Boxplots, violin plots, strip/swarm plots for distribution comparisons.
  - *Matrix & Relations:* Heatmaps with correlation matrices, pair plots, and linear regression fits (`regplot`).

---

### 📈 [Excel, Power Query & DAX Modeling](./EXCEL/)
- **Modern Spreadsheet Functions:** `XLOOKUP`, `INDEX/MATCH`, `LET` (scoped variable assignment), and `LAMBDA` (custom reusable functions).
- **Modern Visuals:** Financial Waterfall charts, Sunburst, Treemap, dynamic in-cell Sparklines, and data bars.
- **ETL & Power Query:** Automated data extraction, column splitting, unpivoting, merging, and appending multi-quarter datasets.
- **Relational Data Modeling ([DAX & Power Pivot](./EXCEL/DAX/)):** Built a **Star Schema** linking `fct_Sales` with dimension tables (`dim_Customer`, `dim_Product`, `dim_Date`), implementing DAX measures and calculated columns.

---

### ⚡ [Power BI](./POWER%20BI/)
- End-to-end data acquisition from heterogeneous sources.
- Data cleansing, type casting, and schema modeling inside Power Query for analytical reporting.

## ⚡ Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/DhruvPanchal0312/Data-Science-and-Analysis-With-GenAI.git
cd "Data Science and Analytics with GenAI"
```

### 2. Set Up Virtual Environment (Recommended)
```bash
# Create virtual environment
python -m venv venv

# Activate environment
# On Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# On macOS/Linux:
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install numpy pandas matplotlib seaborn streamlit jupyter
```

### 4. Run an Interactive App
```bash
# Launch Streamlit Tic-Tac-Toe
cd "NUMPY/TIC TAC TOE- Numpy"
streamlit run "streamlit tic tac toe.py"
```
