1. plt.plot(x,y)
used to plot a graph of any x and y value of same dimensions

2. plt.xlabel("name on x axis")
used to label the x axis

3. plt.ylabel("name on y axis")
used to label the y axis

4. plt.title("title of the graph")
used to give the graph a title

5. plt.figure(figsize=(5,2))
used to design an empty white canvas plot in specific dimensions
