1. plt.plot(x,y)
used to plot a graph of any x and y value of same dimensions

2. plt.xlabel("name on x axis")
used to label the x axis 

3. plt.ylabel("name on y axis")
used to label the y axis

4. plt.title("title of the graph")
used to give the graph a title

5. plt.figure(figsize=(5,2))
used to design an empty white canvas plot in specific dimensions

6. plt.subplot(2,2,4)
used to create the 4 graphs in one screen
subplot(row,columns,index)

7. plt.grid(True)
used to display the grid on the plot

8. ax= fig.add_axes([.1,.1,.8,.8])
used to add axes to the plot

9. (.1,.1) -> location of axes
   (.8,.8) -> size of axes

10. ax.plot(x,y)
    ax.set_xlabel("xlabel")
    ax.set_ylabel("ylabel")
    ax.set_title("title")
    ax.grid(True)

11. plt.plot(x,y,marker="o",linewidth=2.5,label="Meri Line",
            linestyle="--",markersize=10,markeredgecolor='red')
    plt.legend()
    plt.grid(True)
    plt.show()

used to plot line graph
marker -> design of the point
linewidth -> thickness of the line
label -> label of the line
linestyle -> style of the line
markersize -> size of the point
markeredgecolor -> color of the edge of the point

12. xlim() and ylim()
used to apply limit of x and y in graphs

13. use of plt.xlim(-10,70) and
plt.ylim(-100,800) --> applied limit of x and y

14. plt.bar(x,y)
used to plot bar graph

15. plt.barh(x,y)
used to plot horizontal bar graph

16. plt.scatter(x,y), plt.hist(y), plt.boxplot(marks)
used to plot scatterd graph and histogram and boxplot
