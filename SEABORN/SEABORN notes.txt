4. sns.boxplot(x=tips['day'], y=tips['total_bill'])
used to plot a boxplot

5. sns.barplot(x="day" , y="tip", data=tips)
used to get avg on the basis of category 

6. sns.countplot(x="day", data= tips)
used to get count of each category 

7. sns.violinplot(x="day", y="total_bill", data=tips)
used to plot a violinplot showing distribution

8. | Plot        |          Best for                            |
|----------------|----------------------------------------------|
| **barplot**    | Compare average values across categories     |
| **countplot**  | Show how many items fall in each category    |
| **boxplot**    | See median, quartiles, and outliers          |  
| **violinplot** | Same as boxplot + shows distribution         |
| **stripplot**  | View every observation (good for small data) |
| **swarmplot**  | Like stripplot but avoids overlap            |

9. 
| Plot          |          What it shows                                                   |
|---------------|--------------------------------------------------------------------------|
| **histplot**  | Counts of values in bins (shows frequency distribution)                  |
| **kdeplot**   | Smooth curve estimating probability distribution (no bins)               |
| **rugplot**   | Tiny vertical lines for each observation on the axis (rarely used alone) |

10. sns.kdeplot(x=tips['total_bill'], hue=tips['day'], color="purple")
used to plot a kdeplot

11. sns.histplot(tips['total_bill'], bins=50, color="purple")
used to plot a histogram with 50 bins

12. sns.histplot(x=tips['total_bill'], hue=tips['day'],bins=20, kde=True, color="purple")
used to plot a histplot with hue as days
