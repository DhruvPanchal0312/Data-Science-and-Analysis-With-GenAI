| sns.scatterplot     | Plots individual points. Can show clusters and relationships.                                             |
|-----------------------|----------------------------------------------------------------------------------------------------------|
| **sns.lineplot**    | Connects points with lines. Shows trends over ordered categories or time.                              |
| **sns.histplot**    | Shows distribution of a single variable using bins (histogram) or smooth curve (KDE).                  |
| **sns.kdeplot**     | Density plot showing probability distribution. Good for comparing distributions.                         |
| **sns.boxplot**     | Shows median, quartiles, outliers for each category. Good for comparing spread and central tendency.     |
| **sns.violinplot**  | Like boxplot but also shows the distribution shape.                                                      |
| **sns.barplot**     | Shows mean (by default) for each category with confidence interval. Good for comparing averages.         |
| **sns.countplot**   | Counts occurrences of each category. Good for categorical data frequencies.                          |
| **sns.pairplot**    | Shows pairwise relationships for all variables in a dataset. Excellent for initial exploration.        |
| **sns.jointplot**   | Shows bivariate distribution of two variables with marginal distributions.                             |

8. | Plot        |          Best for                            |
|----------------|----------------------------------------------|
| **barplot**    | Compare average values across categories     |
| **countplot**  | Show how many items fall in each category    |
| **boxplot**    | See median, quartiles, and outliers          |  
| **violinplot** | Same as boxplot + shows distribution         |
| **stripplot**  | View every observation (good for small data) |
| **swarmplot**  | Like stripplot but avoids overlap            |

9. 
| Plot          |          What it shows                                                   |
|---------------|--------------------------------------------------------------------------|
| **histplot**  | Counts of values in bins (shows frequency distribution)                  |
| **kdeplot**   | Smooth curve estimating probability distribution (no bins)               |
| **rugplot**   | Tiny vertical lines for each observation on the axis (rarely used alone) |
